# Inventory Management System using MySQL 

This project is a simple inventory management system designed and implemented using MySQL. It demonstrates the creation of relational tables, data entry, and basic query functionalities.

## Features
- Suppliers table
- Products table
- Orders table
- Useful SQL queries for inventory analysis

## Files
- `sql_query_p1.sql`: Contains SQL table creation, data insertion, and queries.
- `SQL - Inventory Management System_utf.csv`: Sample dataset used.

## How to Run
1. Open MySQL Workbench.
2. Execute the queries in `sql_query_p1.sql` step by step.
3. Explore and run custom queries.
